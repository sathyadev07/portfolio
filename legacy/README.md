# Legacy static implementation (archive)

Frozen copy of the pre-React portfolio: `index.html` plus the `source/` scripts and
stylesheet it loads. Kept as the behavioural source of truth for the Galaxy Mode
coordinates, timings and copy that the React app migrated. Not built or served by
Vite — asset references (`assets/…`) resolve only from the repository root, so run
it from the project root with the archived HTML if it needs to be replayed.
